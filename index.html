我的 Spotify
排行榜

上傳從 Spotify 下載的 JSON 串流紀錄檔，支援一次選取多個檔案合併計算。

檔案僅在您的瀏覽器端進行運算，絕對不會上傳到任何伺服器。

怎麼向 Spotify 申請這個檔案？
  1. 登入 Spotify 網頁版，進入您的「帳戶」頁面。
  2. 在左側選單找到並點擊「隱私權設定」。
  3. 捲動到最下方找到「下載您的資料」區塊。
  4. 勾選「帳戶資料」（預設需準備數天），點選「要求資料」。
  5. 收到 Spotify 通知信後下載解壓縮，找出名稱包含 StreamingHistory 的 JSON 檔案上傳（可一次全選上傳）。
